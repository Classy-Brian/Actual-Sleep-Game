# Sleep Mart

**Sleep Mart** is a top-down collection and chase game built in exactly 10 days for B1T Jam 5. Set in a nightmare version of a super market, players must collect pillows and escape the exit before falling into a deep sleep. 

## 🎮 Play the Game
Play the HTML5 web build directly in your browser: [Sleep Mart on itch.io](https://laysus.itch.io/sleep-mart)

## ✨ Core Mechanics
* **The Collection Loop**: Players navigate the HMart map to collect a specific number of pillows required to unlock the exit and "go to bed".
* **The Chaser**: Players must relentlessly evade a Sleep Paralysis Demon. The enemy AI is programmed to constantly and slowly move directly toward the player's coordinates.

## 🛠️ Technical Implementation
* **Game Engine**: Godot 4
* **Art Software**: Aseprite
* **Web Optimization**: The game utilizes Godot's Compatibility renderer to ensure stable, crash-free playback on OpenGL 3/WebGL 2 browsers.
* **The 2-Color Constraint**: This game was designed under the strict B1T Jam 5 rule that allows only 2 visible colors on screen.
